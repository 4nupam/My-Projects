# 🧑‍💻 Personal Portfolio (CV-Style) – React + Vite

This is a **CV-style personal portfolio application** built using **React and Vite**, designed for **clear, structured communication** with recruiters, interviewers, and collaborators.

Rather than focusing on visual design, this project emphasizes:
- **Clean React architecture**
- **Scalable data-driven structure**
- **Real-world frontend engineering practices**

The UI is intentionally simple and functional — the primary goal is to demonstrate **code quality, structure, and maintainability**, not UI/UX design expertise.


---

## 📌 Project Overview

The application presents my professional profile in a **tab-based layout**, similar to a digital CV.  
Each section is easy to navigate, well-structured, and optimized for quick understanding.

### Sections Included:
- **Experience** – Professional work experience
- **Skills** – Frontend, React, and related technical skills
- **Projects** – Real-world and portfolio projects
- **Certificates** – Certifications and achievements
- **Achievements** – Hackathons, recognitions, and milestones
- **Education** – Academic background

Each section is designed with **clarity, scalability, and separation of concerns** in mind.

---

## 🛠 Tech Stack

- **React** – Component-based architecture
- **Vite** – Fast development server and optimized production builds
- **Tailwind CSS** – Utility-first styling for responsive layouts
- **JSON-driven data** – Clean separation between data and UI logic

> ⚠️ Note: UI design is not the focus of this project. Styling is intentionally minimal to keep attention on architecture and implementation.

---

## 📁 Project Structure

To maintain a clean and scalable codebase, all content is **decoupled from components** and stored in JSON files.

### `profile.json`
Contains:
- Personal details
- Work experience
- Skills
- Education
- Certificates
- Achievements

### `projects.json`
Contains:
- Project details
- Tech stack used
- Descriptions
- Relevant links

### Benefits of This Approach:
- Easy to update without touching UI logic
- Highly scalable as experience grows
- Production-ready structure
- No hardcoded content inside components

---

## 🎯 Key Highlights

- Tab-based **CV-style layout** for better communication
- Clean, reusable React components
- JSON-driven architecture (data ≠ UI)

- Optimized production build using Vite
- Focus on maintainability and real-world patterns
